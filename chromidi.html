1. Start Camera

Click ▶ START CAMERA and allow camera access.

2. Pick a Color

Click 🎯 LEARN then click any color in the video to set the detection target. Or drag the HUE / TOL± / S / V sliders manually.

3. Connect MIDI

Open a DAW or virtual MIDI port first. Select it from the header dropdown. MIDI uses WebMIDI (Chrome only).

4. Play!

Move a colored object into frame. The detected hue position within your range maps to a MIDI note. Saturation, brightness, and blob position control CCs. When the blob disappears below the GATE threshold, a Note Off fires.

Tips

Bright, saturated objects work best. Use a coloured cloth, LED, or even a printed card. Try the MIRROR option for live performance.
