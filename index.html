1. Start Camera

Click ▶ START CAMERA and allow camera access.

2. Pick a Color

Click 🎯 LEARN, then click directly on a color in the video feed to auto-tune the detection. Or dial in HUE / TOL± / S / V manually.

3. Connect MIDI

Open a DAW or enable a virtual MIDI port first, then select it in the header dropdown.

4. Play!

CHROMIDI tracks up to 4 separate color blobs simultaneously. Each blob fires on a different MIDI channel (Ch1–Ch4). X position of each blob maps to a scale note. Saturation, brightness, and position control CCs from the primary blob.

Tips

Use bright, saturated objects — coloured tape on your hands works great. Increase TOL± if detection is patchy. Lower GATE to detect small objects. Mirror mode is useful for live performance so movement feels natural.
