Input Source

CAMERA uses your webcam. FILE lets you drop any video file. Use the speed selector (⅛× to 4×) to control playback rate — slowing down directly reduces how often notes trigger.

Color Detection

Set HUE to your target color, TOL± for how wide a range to catch, and S/V to filter out washed-out or dark areas. Up to 4 separate blobs tracked at once.

BPM Gate

When ON, note changes can only fire on each clock pulse. TAP TEMPO sets BPM by tapping. Subdivision controls pulse rate — WHOLE=slowest (1 tick/bar), 32ND=fastest. Enable MIDI CLOCK SYNC to lock to your DAW's transport.

Multi-blob MIDI

Each blob fires on a separate MIDI channel (base Ch + 0/1/2/3). X position maps to a scale note. CCs come from the primary (largest) blob.
